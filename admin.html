Cài đặt thanh toán SePay

Nhập một lần, khách mua hàng sẽ thấy mã QR đúng tài khoản của bạn. Tiền vào là hệ thống tự báo thành công và gửi link tải.

3 bước cài đặt:
1. Điền ngân hàng + số tài khoản bên dưới, bấm Lưu.
2. Bấm “Tạo key”, bấm Lưu, rồi copy key.
3. Vào my.sepay.vn → Tích hợp Webhooks → Thêm webhook: dán URL bên dưới, kiểu chứng thực chọn API Key và dán key vừa copy.
